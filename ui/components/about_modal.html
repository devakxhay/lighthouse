About Lighthouse

Lighthouse is a lightweight, local web deployment manager designed to host your web applications easily on a single Linux server or Raspberry Pi.

Instead of running heavy containers (like Docker), it uses built-in Linux tools like Systemd to run services and Nginx to proxy traffic. It also acts as a local Certificate Authority to sign HTTPS certificates automatically.
